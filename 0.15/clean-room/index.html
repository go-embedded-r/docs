Clean room

v0.12.3: how base R's R code is rewritten and not copied, the similarity gate (cmd/cleanroom, winnowing), its thresholds and audit, the oracle guard and the provenance record. The gate is a floor, not proof.

You are reading the documentation of an outdated version, whose text may no longer be accurate. Go to the latest version.

go-embedded-r/r is BSD-3-Clause and the R code of base R is GPL-2-or-later, so the rule is: base R’s R code is rewritten, never copied. A rule that depends on what a contributor (human or model) remembers is not enough. In v0.12.0, eval/baselib/datetime.R was written from the help pages but partly from memory of R’s code, and came out close to R’s text. It was rewritten in v0.12.2 (pull request 30), and cmd/cleanroom now checks every file of eval/baselib against the R library code of R 4.6.2.

The gate is a floor, not proof. It bounds accidents and careless restructuring. A short function has one natural spelling, so a tiny file can be a copy and pass, and the checker cannot see a rewrite from memory that happens to differ. The provenance record below is the other half, and the gate does not replace the rule.

The similarity checker

  • Method. Our own lexer (package syntax) cuts both files into tokens, comments dropped. K-grams of tokens are hashed and thinned by winnowing (Schleimer, Wilkerson and Aiken, Winnowing: Local Algorithms for Document Fingerprinting, SIGMOD 2003: the minimum hash of each window, the rightmost on a tie; any shared run of k+w-1 tokens shares a fingerprint, and no run shorter than k can). Parameters: k = 8, w = 4.
  • Two views. Identifiers kept (exact), and every identifier replaced by one placeholder (normalised, which sees a renamed copy). The score is containment: the share of our fingerprints found in one R file. The longest common token run is reported with file:line on both sides. Runs count code tokens only (literals and commas do not, so a table of month names is not a copy).
  • Formal argument lists are excluded. function( up to the matching ), defaults included, is not fingerprinted in either view: a help page fixes the signature, so independent code must repeat it.
  • R’s sources are read, never stored. The checker reads src/library/*/R/*.R of an R 4.6.2 tree at check time (RGO_RSOURCE, or --rsrc) and prints only references (file:line), never R’s text.
  • The gate runs in CI. The oracle lane downloads the tarball by SHA-256 and runs the gate there (RGO_REQUIRE_RSOURCE=1: the gate must run, not skip). It also runs as a Go test, which skips without R’s sources.

Three files were rewritten clean room in v0.12.2 (pull request 30): datetime.R (written without the old file or R’s R sources, from the Rd pages and oracle experiments), vectors.R (ifelse, append, isTRUE/isFALSE, NROW/NCOL) and conditions.R. Behaviour did not change: 2 028 of 2 028 goldens, and the datetime fuzz against the old file gave the same results with the same four counted exclusions.

A failed first draft becomes a Go native

Since v0.14.1: a baselib function whose first draft fails the gate is implemented as a Go native from the Rd page and the oracle, never reshaped in R, and the failed first-draft score is recorded in the pull request. Reshaping a draft until the gate passes would make the gate the target. The cases that fixed the rule (pull request 36):

FunctionFirst draft, blind, from rle.Rd / scale.Rd and the oracleGateNow
rle, inverse.rlelongest exact run 51 tokens, normalised 64, against base/R/rle.R (a blind author converged on R’s own run)40 and 60eval/rle.go
scale.defaultexact containment 0.26 against base/R/scale.R0.20eval/scale.go (R keeps the generic and a thin method)

The v0.14.0 drafts of the same functions had been reshaped to pass (the “redesigned” rows of the repository’s gate table); that is what the rule now forbids. The submitted scale_rle.R scores 0.00 exact, 0.45 normalised, longest run 10 tokens.

The oracle guard

Printing a base function in the reference R shows its GPL body, and this happened once while checking a behaviour. internal/oracle/oracle.R therefore refuses, with the error oracle: printing base closures is disallowed by the clean-room rule, to print, deparse, dput, body, as.list, format, serialize or return any closure of base, stats, utils, methods and the other packages of R, however it is reached (auto-print, :::, getAnywhere, inside a list or an attribute, or a copy made in the global environment, recognised with identical() against the bodies and formals of every function of those packages, at any size, including copies made with body<-, attr<- or as.function). .Internal is refused in requests. Closures of our own print, and goldens that compare function printing use closures defined in the snippet.

Until v0.12.3 a base closure whose body was under 100 serialized bytes could be copied out of the namespace and printed (issue 31, closed by pull request 32); the size floor is gone. Someone with an installed R can still read its sources, which is why the rule is procedural too.

Provenance in every pull request

.github/pull_request_template.md asks, for any change under eval/baselib/: the .Rd pages read, whether any R function body was seen and how (and who then rewrote the file blind), and the gate score of the first draft before any reshaping. Pull request 30 records its own provenance: datetime.R and vectors.R were rewritten by the agent that built the gate, which saw only the checker’s references and scores; conditions.R was rewritten blind by a separate agent, after the first rewrite was replaced because its author had read the old 10-line file; that agent saw one base closure’s printed body when the oracle printed it, which is why the guard exists.

Run it 

export RGO_RSOURCE=/path/to/R-4.6.2          # an unpacked, checked R source tree
go run ./cmd/cleanroom check                 # eval/baselib/*.R; exit 1 over the gate
go run ./cmd/cleanroom check --list 20 f.R   # every shared run of 20+ tokens, as file:line
go run ./cmd/cleanroom floor some/*.R        # the same scores for independent code
go test ./internal/cleanroom ./cmd/cleanroom # the gate as a test; skips without R's sources
